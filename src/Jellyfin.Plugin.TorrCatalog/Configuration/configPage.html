Prowlarr

Prowlarr → Settings → General → API Key. Stored server-side only.

TorrServer

Players are redirected to TorrServer streams, so this address must be reachable from clients (TV, phone), not only from Jellyfin.
After this the next best release is tried (up to 3).

Fallback library (transcoding)

Virtual items can only be direct played. When a client can't play any release (e.g. a browser and HEVC/AC3), the item is written as a .strm into a "TorrCatalog Movies/Shows" library and Jellyfin plays it, transcoding if needed. Leave the path empty to disable.
Must be reachable by Jellyfin itself and by clients. Empty = http://localhost:<port> (server-side only).

Catalog sections

Each enabled section appears as a virtual movie library (and a "Latest" row on Home). Path is relative to api.themoviedb.org/3/, e.g. trending/movie/week or discover/movie with query sort_by=popularity.desc&with_genres=16. Keep a section's Id stable once used.
